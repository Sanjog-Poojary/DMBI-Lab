# CA1 / CA2 Proof-of-Concept — Video Streaming Platform BI

This folder contains the analysis pipeline and Streamlit dashboard for the
DMBI CA1 and CA2 components.

## Folder layout

```
CA1_CA2_POC/
├── data/
│   └── streaming_platform_dataset.csv   # 515 synthetic subscriber records
├── src/
│   └── poc_pipeline.py                  # Analysis functions (import, do not edit)
├── outputs/
│   └── poc_results.json                 # Reference numbers generated by the pipeline
└── app/
    ├── app.py                           # Streamlit dashboard (6 pages)
    ├── helpers.py                       # Shared UI utilities
    └── requirements.txt
```

## Run the analysis pipeline

```bash
python CA1_CA2_POC/src/poc_pipeline.py
```

Writes `CA1_CA2_POC/outputs/poc_results.json`.

## Run the app

**Option 1 — Windows Batch File (Easiest):**

Double-click `run_app.bat` in the repository root, or run:

```cmd
run_app.bat
```

**Option 2 — CLI command from repository root:**

```bash
streamlit run CA1_CA2_POC/app/app.py
```

The app opens at http://localhost:8501 in your browser.

### First run — CA3 viewing sessions

If `CA3/data/viewing_sessions.csv` is missing, generate it first:

```bash
python CA3/src/generate_viewing_sessions.py
```

Or open the **Recommendations** page in the app — it auto-generates the file.

## Dashboard pages

| Page | Module | What it shows |
|---|---|---|
| Overview | II | KPIs, before/after cleaning table |
| Warehouse & OLAP | I | Star schema, roll-up heatmap, slice bar, dice table |
| Outliers | IV | Box plot, IQR and Isolation Forest counts |
| Segments | IV | Silhouette chart, PCA scatter, cluster profile |
| Churn model | III | DT / NB / RF metrics, confusion matrix, DT rules |
| Recommendations | V & VI | Apriori rules, user genre recommender |
