# DMBI Lab — Video Streaming Platform (Roll No. 40)

Dataset and problem statement: a video streaming platform's subscriber, viewing, and revenue data.

| Folder | Experiment | Contents |
|---|---|---|
| `Exp1_Star_Snowflake_Schema/` | Design star and snowflake schema | Document, schema diagrams, diagram generator |
| `Exp2_Data_Preprocessing/` | Data preprocessing in Python | Document, dataset, preprocessing script |
| `Exp3_EDA_Visualization/` | Exploratory data analysis and visualization | Document, dataset, EDA script |
| `Exp4_Classification/` | Classification (Decision Tree, Naïve Bayes) | Document, dataset, classification script |
| `Exp5_Custom_Classification/` | Classification with inbuilt and custom functions | Document, dataset, custom classification script |

Run each script from inside its own folder, e.g. `cd Exp2_Data_Preprocessing && python code/preprocessing.py`.
