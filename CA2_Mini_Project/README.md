## Execution Instructions

### 1. Run the Analysis Pipeline

From the repository root:

```bash
python CA2_Mini_Project/src/poc_pipeline.py
```

This performs automated deduplication, imputation, star schema generation, outlier detection, silhouette evaluation, and churn modeling with balanced class weights, writing outputs to `CA2_Mini_Project/outputs/poc_results.json`.

### 2. Launch the Streamlit BI Dashboard

**Option 1 — Batch file (Recommended on Windows):**
Double-click `run_app.bat` in the repository root (or inside `CA2_Mini_Project/`).

**Option 2 — CLI command:**

```bash
streamlit run CA2_Mini_Project/app/app.py
```

The application will launch in your default web browser at `http://localhost:8501`.

## Dashboard Pages & Coursework Modules

| Tab | DMBI Module | Functionality & Features |
|---|---|---|
| **Overview** | Module II: Data Preprocessing | Raw vs Cleaned KPI cards, before/after cleaning audit table, watch minute capping |
| **Warehouse & OLAP** | Module I: Data Warehousing | Star schema viewer (Fact & Dims), Roll-up heatmap (Tier × Genre), Slice bar (Premium spend), Dice table (Tier × Country) |
| **Outliers** | Module IV: Outlier Analysis | Box plot of watch durations, IQR boundary calculation (2 flagged), Isolation Forest detection (25 flagged) |
| **Segments** | Module IV: Cluster Analysis | K-Means silhouette curve ($k=2..7$, best $k=2$), 2D PCA cluster projection, cluster profiling |
| **Churn Model** | Module III: Classification | Decision Tree, Gaussian Naïve Bayes, Random Forest with balanced class weights; confusion matrix heatmap; tree rule dump |
| **Recommendations** | Module V & VI: Association & Recommenders | Apriori association rules, interactive genre recommendation engine |
